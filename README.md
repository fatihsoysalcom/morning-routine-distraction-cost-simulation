# Morning Routine Distraction Cost Simulation

This example simulates two morning routines to illustrate the hidden cost of starting the day with distractions like email. It compares a 'distraction-first' approach with a 'focused-work-first' approach, demonstrating how context switching can lead to significant time loss, as discussed in the accompanying article.

## Language

`python`

## How to Run

Save the code as `main.py`.
Run from your terminal: `python main.py`
